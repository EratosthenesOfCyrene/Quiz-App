# Quiz App

A browser-based quiz application built with HTML, CSS and JavaScript.

The application allows users to answer multiple-choice questions, receive immediate feedback and track their score throughout the quiz.

The project was created as an earlier learning project to practise JavaScript fundamentals, DOM manipulation and interactive user interfaces.

The project gave me experience with:

- working with arrays and objects

- accessing and modifying HTML elements through the DOM

- evaluating selected answers
- dynamically changing CSS classes
- tracking application state such as the current question and score
- rendering changing content without reloading the page
- restarting and resetting global application state

## Application logic

Quiz questions and their possible answers are stored as JavaScript data structures.

During the quiz, the application:

1. loads the current question and its possible answers
2. displays the available answer options
3. evaluates the selected answer
4. provides visual feedback (wrong or right answer chosen)
5. updates the score
6. loads the next question
7. displays the final result when the quiz is completed

This structure helped me understand how application state, user interaction and dynamic interface updates work together in a JavaScript application.
